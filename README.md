## 📖 课文原文

1947年1月12日，天阴沉沉的，国民党反动派包围了云周西村。

由于叛徒的出卖，年轻的共产党员刘胡兰被捕了，关在一座庙里。

敌人问刘胡兰："现在有人供出你是共产党员！你们村里还有谁是？"

刘胡兰回答："就我一个！"

敌人想收买刘胡兰，对她说："说出来，就给你一份地。"

刘胡兰大声回答："给我一个金人，我也不说！"

敌人又威胁她说："不说就打死你！"

刘胡兰愤怒地回答："打死也不说！"刘胡兰像钢铁铸成似的，一点儿也不动摇。

敌人把刘胡兰拉到庙门口的广场上，当着她和乡亲们的面，铡死了被捕的六名革命群众。

敌人指着血淋淋的铡刀说："再不说，也铡死你！"

刘胡兰挺起胸膛说："要杀要砍由你们，怕死不当共产党员！"

她迎着呼呼的北风，踏着烈士的鲜血，走到铡刀前。

刘胡兰光荣地牺牲了，那年她才十五岁。

毛主席听到这个消息，亲笔为她写了题词："生的伟大，死的光荣。"

## 📝 课后习题

### 一、朗读课文

> **要求：** 读出刘胡兰坚定、英勇的语气。注意敌人和刘胡兰对话的不同语气对比。

**朗读指导：**

- 敌人的话：**威胁、凶狠**（读得粗重急促），或**狡猾、利诱**（读得假惺惺）
- 刘胡兰的话：**坚定、响亮、一字一顿**
- 课文叙述部分：**庄重、缓慢、饱含敬意**

---

### 二、思考：从哪些地方看出刘胡兰"一点儿也不动摇"？

（课文中多次描写敌人威逼利诱，刘胡兰始终坚定回答，找出相关句子）

**参考分析：**

| 敌人的手段 | 刘胡兰的回答 | 表现的精神 |
| ---------- | ------------ | ---------- |
| 问她村里还有谁是共产党员 | "就我一个！" | 不牵连别人 |
| 用"一份地"收买 | "给我一个金人，我也不说！" | 不受利诱 |
| 用"打死你"威胁 | "打死也不说！" | 不怕威胁 |
| 用铡刀恐吓 | "要杀要砍由你们，怕死不当共产党员！" | 视死如归 |

→ 小结：敌人从**利诱**到**威胁**再到**恐怖手段**，刘胡兰的回答一次比一次坚定，"像钢铁铸成似的"，所以说她"一点儿也不动摇"。

---

### 三、联系上下文，理解词语意思

#### 1️⃣ 敌人想**收买**刘胡兰

> **原意：** 用钱物等好处使别人替自己做事或为自己隐瞒。
> **文中意思：** 敌人用"给一份地"这种物质利益，想让刘胡兰说出其他共产党员的名字。这里的"收买"是**贬义**，指用利益诱惑他人背叛。

#### 2️⃣ 敌人又**威胁**她说："不说就打死你！"

> **原意：** 用武力或权势逼迫别人顺从。
> **文中意思：** 敌人见利诱没用，就用"打死"的武力来逼迫刘胡兰屈服。

#### 3️⃣ 刘胡兰光荣地**牺牲**了，那年她才十五岁

> **原意：** 为了正义的目的舍弃自己的生命。
> **文中意思：** 刘胡兰为了保护村里的共产党员，英勇就义，献出了宝贵的生命。"牺牲"在这里是**褒义**，专指为正义事业而献身。
